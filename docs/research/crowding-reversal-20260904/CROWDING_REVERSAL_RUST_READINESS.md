# BTC/ETH 拥挤反转：Rust 实现前回测确认

## 决策

**回测层面通过，允许进入 Rust 参考引擎与前向纸面交易实现；不等于批准全资金实盘。**

本次没有重新挑参数，只重放已经冻结的 24% 目标波动版本：BTCUSDT/ETHUSDT USD-M 永续、4h、Binance 全市场账户多空比、30/60/120日趋势至少2票、12个拥挤参数成员等权、历史资金费、5bp/边成本、信号延迟一根4h、总名义不超过净值100%。

## 数据与因果审计

- 六个源文件均无重复时间戳；BTC/ETH 1m价格文件内部无断点。
- 组合4h索引严格递增、无重复，所有相邻时间差均为4h。
- 七个跨年度截止点分别只用当时以前的数据重算，和全历史对应时点的目标仓位最大误差为0。
- `position[t] = target[t-1]` 最大误差为0，确保收盘信号不会用于刚结束的4h收益。
- `net = price_pnl + funding_pnl - cost` 最大误差为0。
- 历史最大总名义仓位为1.0，没有用杠杆把年化强行抬高。
- 2021-12-30 20:00 至2022-01-19 12:00存在119根4h的共同指标缺口。策略在其中118根为空仓，整段收益 -0.23%，因此缺口没有制造利润。
- 将4h聚合改成标准 `[起点,终点)` 完成区间后，开发/验证 CAGR 为28.84%/38.49%，回撤 -8.16%/-9.17%；一分钟边界语义不是收益来源。
- 15m永续价格和15m现货价格代理复核的验证CAGR为35.61%/35.28%。
- 36个有限参数邻域全部在开发和验证两段为正，其中21个两段均超过20%。
- 只用2021-07至2022年末数据选择的趋势变体，2023年CAGR 55.47%，2024+ CAGR 30.13%。
- 反转全部仓位方向后，开发/验证CAGR为 -26.54%/-33.58%。

## 仍然不能消除的证据风险

1. 只有四个完整自然年；Bootstrap的2024+ CAGR 95%区间为13.13%–49.24%，下界低于20%。
2. 2024+已被本项目多轮查看，不能继续冒充全新盲测。
3. 拥挤优势来自Binance参与者结构，尚未用OKX/Bybit同口径历史数据跨所复现。
4. 回测没有L2排队、真实市场冲击、API故障、强平、交易所或稳定币尾部风险。
5. 月度和周度并不稳定：验证期正收益月66.67%，正收益周仅约41.5%；它适合长期增长研究，不是月薪策略。

## Rust 必须逐项复现的数值约定

- 4h主时钟为UTC；当前Python参考使用右闭合聚合，并延迟一根4h执行。原始1m K线时间戳是开盘时间，因此线上收集器必须等待边界分钟完全结束后才发布决策。
- `ln(globalLongShortAccountRatio)`；滚动标准差使用样本标准差 `ddof=1`。
- z-score当前已完成观察值可以进入滚动窗口；窗口最少需要80%有效值。
- 波动和协方差使用历史4h简单收益、样本方差/协方差、年化因子 `6 × 365.25`。
- 每个成员先独立逆波动率和目标波动缩放、总名义封顶1.0，再将12个成员目标等权平均并净额化。
- 趋势使用30/60/120日简单价格动量，至少2票与候选仓位同向；不足历史的数据不能作为空头票。
- 任一拥挤观测缺失，相关成员立即归零；禁止前填、后填。
- 正资金费由多头支付：`funding_pnl = -position × funding_rate`。
- 换手成本：`abs(new_position - old_position) × 0.0005`。
- Rust与黄金文件逐根目标仓位建议绝对误差不超过 `1e-10`；逐根净收益误差不超过 `1e-12`；最终净值相对误差不超过 `1e-9`。
